# ADR 0002: SHA-256 Only (No BLAKE3)

**Date:** 2026-04-09
**Status:** Accepted

## Context

The Rust version defaulted to BLAKE3 (4-10x faster than SHA-256) with SHA-256 available via the `sha256` feature flag. BLAKE3 is not available in the Cyrius stdlib and would require porting ~2,000 lines of SIMD-optimized code.

## Decision

Use SHA-256 (FIPS 180-4) exclusively. Implement from scratch in Cyrius (~250 lines).

## Consequences

- SHA-256 is universally recognized and FIPS compliant
- No SIMD optimization — pure scalar 32-bit masked arithmetic on i64 values
- Performance is adequate: 9us per 64-byte hash, 1.4ms to verify 100-entry chain
- BLAKE3 can be added later if Cyrius stdlib gains crypto modules
- Existing Rust chains using BLAKE3 are not cross-verifiable with Cyrius chains (expected — the `hash_algorithm` field documents which algorithm was used)
